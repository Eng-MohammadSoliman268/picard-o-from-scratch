# Changelog

## v1.0.0 — 2026-10-04

- First frozen validated Orthogonal Picard ICA core.
- NumPy CPU backend.
- CuPy CUDA backend.
- Centering, rank estimation, whitening and dewhitening.
- Tanh contrast with analytic score and derivative.
- Orthogonal relative gradient.
- Picard Hessian approximation with regularization.
- Preconditioned L-BFGS memory and two-loop recursion.
- Matrix exponential orthogonal update.
- Backtracking line search and gradient fallback.
- High-level system API and standalone single-file implementation.
- Synthetic and HBN validation workflow completed against official Picard-O.
